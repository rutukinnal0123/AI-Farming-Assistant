# AI-Farming-Assistant
An AI-powered farming assistant that helps farmers identify crop diseases and answer agriculture-related queries using **Computer Vision, Multimodal AI, and Retrieval-Augmented Generation (RAG)**.

## Features

* 🌱 **Plant Disease Detection**

  * Upload a crop leaf image.
  * Deep Learning (CNN/EfficientNet-B3) predicts the crop disease with high accuracy.
  * Returns the predicted crop, disease name, confidence score, and top predictions.

* 🤖 **AI Farming Assistant**

  * Ask agriculture-related questions in natural language.
  * Receive context-aware responses powered by RAG.

* 📚 **Retrieval-Augmented Generation (RAG)**

  * Retrieves relevant agricultural knowledge before generating responses.
  * Improves factual accuracy and provides more reliable answers.

* 🖼️ **Multimodal AI**

  * Supports both image-based disease diagnosis and text-based farming assistance.

* 🌾 **Farmer-Friendly Support**

  * Designed to assist farmers with crop health monitoring and agricultural guidance.

## Technologies Used

* Python
* TensorFlow / Keras
* EfficientNet-B3 (Transfer Learning)
* OpenCV
* NumPy
* Flask
* Retrieval-Augmented Generation (RAG)
* Machine Learning & Deep Learning

## Project Overview

The system combines deep learning–based plant disease classification with an AI-powered knowledge retrieval system. Users can upload an image of a crop leaf to identify diseases or ask farming-related questions to receive intelligent, context-aware responses.

This integration of **Computer Vision + RAG + Multimodal AI** creates a comprehensive farming assistant capable of supporting both disease diagnosis and agricultural decision-making.
